# 离线迁移

> [English](README.md) | 中文

`legacy` 读取固定的 `281889e5` Fleet、Agent、Thread 和 Memory 格式，不打开
具有恢复写入行为的旧存储。它保留原始文件字节、按序历史事实、当前 Generation
的完整上下文、终态 Input、Memory 知识/回执/删除约束，以及模块和扩展的私有文件，
不访问数据库、服务、模型或工具。

读取成功表示批次、游标、身份、用量和源文件稳定性检查通过，不表示运行中的
Fleet 已经静止。合法空输入队列的文件缺席也会记录，并在捕获结束前再次检查。
未完成批次、未知事实、未结算输入、有歧义的 Thread 名称、不一致投影，以及未完成
的 Memory/配置事务会被拒绝，不会修复源文件。
即使最后一次 Turn 失败，Worker 的保留状态仍以归档、恢复的 metadata 为准。
Memory 禁存范围保留原始作用域，包括跨 Generation 的范围。

Agent 捕获包括被引用的媒体和 spool 文件内容，并验证其 hash。Fleet 捕获要求明确
提供源用户的默认 Home，保留配置层和导入缓存字节，并记录配置缺席。对于外部
Workspace，只读取配置，不接管其所有权，也不复制其中的任意文件。保留配置或扩展
私有文件并不表示已经完成行为转换。用户切换前，完整迁移仍需通过可校验备份、
各服务所属的导入流程和行为验收。
