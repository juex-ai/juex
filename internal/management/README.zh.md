# Management

> [English](README.md) | 中文

Management 拥有全局用户、租户、成员关系，以及用户在每个租户内的唯一 Fleet。登录凭据与稳定 User 身份分离。PostgreSQL adapter 拥有 `management` schema；其他服务通过业务接口调用，不直接写入这些表。App 负责数据库连接与组装。

已认证的 Management HTTP 服务和 Web 使用此目录。`CreateUser` 是身份创建原语，`CreateTenant` 是运维操作，两者都不是公开注册入口。适配器必须从已认证会话取得 actor ID。成员操作传入的角色是修改目标，不是调用者权限证明。

每个成员写入操作先锁定 Tenant 行，再读取当前权限并检查最后一位有效管理员。成员变更、actor/owner 审计事实与执行代际在同一事务提交。恢复访问不会回退代际；Runtime、Execution 和应用重新检查代际，即使停用和恢复都发生在两次检查之间，也能阻止旧工作继续。审计默认保留 90 天，运维可通过 `--audit-days` 调整；保留策略不删除权限代际、业务历史或恢复收据。

接受邀请要求登录匹配的账号，不会验证邮箱。令牌单次使用、有期限、以摘要保存，重新签发使旧令牌失效。已移除成员只能接受新邀请恢复，沿用保留的 Fleet。创建邀请时返回令牌原文；加密副本支持 Dashboard 持续展示复制链接，摘要不能还原邀请链接。

密码使用限制资源消耗的 Argon2id；人工登录会话与能力令牌保存摘要。受邀注册不能重置已有账号。初始化与运维恢复没有公开 HTTP 入口。密码恢复撤销人工登录会话，与设备凭据、Agent 执行独立。接受邀请不代表邮箱验证；SMTP 密码恢复要求通过独立流程验证邮箱。

邮件正文加密后与业务事务一起进入队列。发送器单独记录 SMTP 接收状态，不混淆邀请状态。重试沿用消息 ID；连接状态不明确时，SMTP 无法保证恰好一次投递。确认发送后清除队列中的能力链接正文。公开 API 响应不包含密码摘要、Provider 密钥或平台加密密钥。

`Fleet` 仅授权读取。有效租户管理员可以查看已移除或停用成员的保留数据；读取结果不授予配置修改或执行权。代管读取同时记录 actor 与 owner。执行及设备许可授权是独立操作。

Tenant、Fleet、已接受的 Workspace 快照与 Agent 声明依次覆盖：最高层模型列表替换
整条顺序，模块显式开关逐项覆盖；模块预设提供显式开关之下的默认值。省略声明保留
原值，空声明恢复继承。Memory 和 Calendar 各自拥有应用启用状态和执行代际；
Dashboard 通过经过认证的应用 API 读取和配置各服务，不维护重复开关。

Management 拥有解析后的 Agent 能力策略。收紧策略与推进 Agent 执行代际在同一事务提交。Runtime 为每个
Turn 固定策略并与当前权限取交集；Execution 和应用所有者通过相同权限快照检查
各自操作。单个 Agent 的应用限制不改变 Fleet 应用启用状态，也不删除应用历史。

Agent 管理是单独、默认关闭且由人工授予的权限，不继承模块配置，也不能由模型修改。
它只允许普通 Main 管理同一所有者 Fleet 中的其他 Agent。撤权推进执行代际，再次授予
不能复活冻结 Turn。配置补丁只暴露安全的类型化字段，保留未指定的 Hook、环境变量和其他
设置。Management 变更与绑定来源的回执原子提交。重试先恢复原有最小回执，否则检查当前
权限与目标版本。取消可为尚未提交的意图记录终态拒绝，阻止迟到请求之后执行。

私有进程变量使用独立加密声明，遵循相同四层顺序；公开读取只返回键名和来源。
Tenant 值向其获准的 Agents 共享，只有管理员可写；Fleet 值归单个用户所有。
Workspace 值只在绑定环境与目录内生效。删除键恢复继承，设备撤权后仍可删除；
删除不能改变剩余值的绑定。空字符串是显式值。有效值变化在同一事务内撤销受影响
Agent 的旧授权。只有 Execution 可按原操作权限解析值，Provider 凭据独立管理。
界面不会隐式读取本机 `.env` 文件。

动态指令来源需显式启用，默认关闭。可选全局路径属于选定的执行环境。其他配置编辑
省略此设置时保留原值；关闭或更换已启用的来源时，与配置写入一起推进 Agent 执行代际。

离线 Agent 导入在同一事务内创建定义、审计和源身份回执。首次导入要求 Fleet 没有
Agent 或清理历史；调用方固定该 Fleet 身份并停止目标写入进程。完全相同的重试只
恢复 ID，不重置之后的配置、归档状态或执行代际，即使原模型已不可用。当前成员权限
和清理检查仍然生效。返回的 ID 不授予权限；其他所有者的后续迁移步骤必须重新授权。
此私有边界不导入资源，也不提供 HTTP 路由。

模型由部署方提供。租户默认继承目录，也可使用显式允许列表；空列表不授予任何模型。Fleet 默认继承平台模型，Agent 可以覆盖；运维配置有序、不递归展开的回退列表。
快照接纳与每次凭据解析都在一个 Management 事务内检查当前资源权限。模型和租户访问代际防止撤销再恢复使旧 Turn 授权复活，未受影响的候选仍可用。
API 密钥轮换不改变已固定的路由；端点、协议、限制或私有 Provider 选项变化会推进模型代际，账号切换后再恢复也不例外。
私有请求头／查询参数、推理和能力／兼容性选项随模型加密保存，只在重新授权后返回 Runtime；公开目录和固定的 Turn 不复制这些值。
Provider 名称不覆盖显式协议。托管 Codex 必须配置固定、显式的 `ChatGPT-Account-ID`，token 轮换不能隐式选择账号。
无认证的本地 OpenAI 兼容端点必须明确选择 `none` 认证，不发送 Authorization 请求头或虚构的 API 密钥。
授权接纳在外部请求之前结束：撤销阻止后续接纳，不能撤回已发出的请求。

离线模型导入在一个事务内初始化空部署模型目录和未设置的租户模型策略，保存加密
配置、直接 fallback、显式允许列表及目录所属回执，保持平台默认模型不变。
私有输入完全一致的重试只恢复 UUID，不恢复后续凭据或策略修改。回执在 Fleet
清理后保留，不授予执行权限。

普通请求输出上限与正的上下文预留量分别配置。零上限沿用适配器／Provider 默认，
不承诺无限输出，也不保证 Provider 只使用预留的 token。Anthropic 的预留量至少覆盖
适配器默认的 4096 token。两项配置都固定到模型计划；修改任意一项会使旧候选失效。

通过 `postgres.Migrate` 显式初始化 schema，迁移在事务中串行执行并校验摘要；未知或被修改的版本直接失败，不静默修复。`tests/e2e` 的数据库集成测试使用 `postgres` build tag，要求 `JUEX_TEST_POSTGRES_URL` 指向有建库权限的临时测试服务器。每个用例创建和删除独立数据库。CI 使用 PostgreSQL 18 执行这些用例。

持久站内通知归每个租户中的资源所有者。只有该登录用户能读取、修改已读状态和投递偏好；
Fleet 代管权限不授予个人通知权限。应用、Fleet 与事件身份对不可变载荷去重。
完成通知需主动开启，提醒与需要处理的事件默认显示；偏好影响之后产生的通知。
每次业务邮件发送前核对当前成员状态、已验证的当前邮箱及投递偏好。邮件只含需登录的
站内通知链接，不携带应用证据或对话内容。SMTP 重试保留消息身份，但不能保证远端恰好一次投递。

永久清理以持久任务处理归档 Agent 或已移除成员的 Fleet。Management 固定目标身份，先让所有服务阻止新工作，再逐项清理，并分别确认和重试。服务保留清理标记，拒绝迟到写入和旧资源重建。平台数据清理与外部操作停止核验分别展示。用量和审计保留；Fleet 清理后，原用户重新接受邀请才创建新 Fleet。历史备份按部署方保留策略过期。

执行端扩展是 Agent 所有的配置快照，绑定已授权环境和明确目录。导入接受 Execution 的检查回执，不接受浏览器提交的 manifest 或技能正文；当前文件权限及其版本仍须匹配。配置写入验证完整的派生 Hook 集合。移除资源、停用绑定或停用内嵌 Hook 都会推进执行 epoch，设备上已安装的文件保持不变。
